GAME TITLE : Ringoban
GAME NAME  : ringoban
FOLDER     : game_ringoban
==============================================================================

ABOUT
-----
A Sokoban clone in Applesoft BASIC: push the boxes onto the marked target
spaces through 90 levels, one move can be undone, and positions can be saved
mid-level. Uses MouseText and ProDOS; this disk holds the compiled, responsive
version.

FILES
-----
Ringoban1.5-final.dsk (ProDOS); disk_contents/ (every file from the disk
image, named NAME#TTAAAA). Documents: Tech-Ringoban-Notes.pdf (technical
notes), disk sleeve ringoban.pdf. Screenshots: ringoban1-6.jpg and label.png.
The Applesoft source is not on the disk (compiled version), so there is no
BASIC listing.
