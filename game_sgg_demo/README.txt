GAME TITLE : Sean's Garage Giveaway
GAME NAME  : sgg_demo
FOLDER     : game_sgg_demo
==============================================================================

ABOUT
-----
Sean opens his garage: grab everything as fast as you can in this fast-paced
Double Hi-Res game (128K Apple //e). Demo version.

FILES
-----
game_sgg_demo.po (ProDOS); disk_contents/ (every file from the disk image,
named NAME#TTAAAA). The game is written in PLASMA rather than Applesoft BASIC
or hand-written 6502 assembly, so there are no source listings.
