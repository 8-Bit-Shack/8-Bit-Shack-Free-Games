==============================================================================
GAME TITLE : Mined Out
GAME NAME  : mined_out
FOLDER     : game_mined_out
==============================================================================

ABOUT
-----
Navigate through the minefields from bottom to top using the keys A, Z, N and
M. Mines are marked with "*" and you are warned of any mines next to your
position. Apple II version of the classic game, with MockingBoard music.

FILES
-----
game_mined_out.dsk (DOS 3.3); source/ (Applesoft BASIC listings as .bas.txt
and Merlin 6502 source as .s); disk_contents/ (every file from the disk image,
named NAME#TTAAAA).
