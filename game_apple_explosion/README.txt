==============================================================================
GAME TITLE : Apple Explosion
GAME NAME  : apple_explosion
FOLDER     : game_apple_explosion
==============================================================================

ABOUT
-----
Minesweeper-style game for the Apple II (version 1.02, 48K edition). Use the
A, Z, N and M keys to move the pointer around the grid, SPACE to uncover the
current square and RETURN to mark an apple for detonation. If you have ever
played Minesweeper you will know how to play Apple Explosion; if not, prepare
to die! Includes music and sound effects.

FILES
-----
game_apple_explosion_v1.02.dsk (DOS 3.3); source/ (Applesoft BASIC listings as
.bas.txt and Merlin 6502 source as .s); disk_contents/ (every file from the
disk image, named NAME#TTAAAA). The disk also holds a "READ ME - GAME INFO"
text file with the game instructions.
