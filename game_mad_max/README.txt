==============================================================================
GAME TITLE : Mad Max
GAME NAME  : mad_max
FOLDER     : game_mad_max
==============================================================================

ABOUT
-----
Hi-res maze game: collect all the bones on each level while avoiding the
enemies, and keep your lives. Keyboard and joystick versions are on the disk.
Keys are configurable.

FILES
-----
madmax.dsk (DOS 3.3); source/ (Applesoft BASIC listings as .bas.txt and Merlin
6502 source as .s); disk_contents/ (every file from the disk image, named
NAME#TTAAAA). Screenshots: madmax1.png, madmax2.png, madmax3.png.
