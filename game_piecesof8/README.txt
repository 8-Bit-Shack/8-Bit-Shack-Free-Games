==============================================================================
GAME TITLE : Pieces of Eight
GAME NAME  : piecesof8
FOLDER     : game_piecesof8
==============================================================================

ABOUT
-----
Pirate-themed game: move with the arrow keys, fire with the space bar and
collect the loot. The game has a title screen, play screens and a win screen.

FILES
-----
game_piecesof8.dsk (ProDOS); source/ (Applesoft BASIC listings as .bas.txt and
Merlin 6502 source as .s); disk_contents/ (every file from the disk image,
named NAME#TTAAAA).
