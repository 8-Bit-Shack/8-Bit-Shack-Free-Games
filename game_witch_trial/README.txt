ABOUT
-----
Double Lo-Res adventure game, version 2.0 (2026), told through a series of
Double Lo-Res screens drawn by Dan Henderson. Requires an enhanced Apple //e,
//c or IIgs (65C02, 128K); mouse, joystick or arrow keys with Space/Return; a
MockingBoard is needed for the music. The game checks your system at startup.

FILES
-----
WitchTrial_V2.po (ProDOS, 800K); source/ (Applesoft BASIC listings as .bas.txt
and Merlin 6502 source as .s); disk_contents/ (every file from the disk image,
named NAME#TTAAAA).
