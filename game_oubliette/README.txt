ABOUT
-----
Oubliette is a unique puzzle game with new challenges on each level. Without
giving too much away, you need to escape each dungeon using a sequence of
doors and keys. Do not rely on linear thinking, things are not always as they
seem. You may need a pen and paper for the more complex puzzles. Keyboard
control: the keys are preset to A, Z, N and M and you can choose your own in
the game menu (uppercase). Runs on the Apple II+, IIe, IIc and IIgs at any
speed (best at 1 to 3 MHz); make sure uppercase is selected before you start.
Sound effects by Tom Porter.

FILES
-----
OUB.dsk (DOS 3.3); Oubliette.pdf (the game manual); disk sleeve oubliette.pdf
(the disk sleeve); Oubliette.png (title banner); source/ (Applesoft BASIC
listings as .bas.txt and Merlin 6502 source as .s); disk_contents/ (every file
from the disk image, named NAME#TTAAAA). Each level is an independent BASIC
program that loads from the previous one.

ATTRIBUTION
