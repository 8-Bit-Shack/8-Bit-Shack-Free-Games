GAME TITLE : Minesweeper
GAME NAME  : minesweeper
FOLDER     : game_minesweeper
==============================================================================

ABOUT
-----
Double Lo-Res Minesweeper for the Apple //e (128K). Configurable keys, a
loading screen, and a game over screen. Two disks are included: the standard
version and a compiled version.

FILES
-----
Minesweeper.dsk (DOS 3.3) and Minesweeper compiled.do (DOS 3.3, compiled);
source/ (Applesoft BASIC listings as .bas.txt and Merlin 6502 source as .s);
disk_contents/ (every file from the disk image, named NAME#TTAAAA, one folder
per disk). Screenshots: mine1.png, mine2.png, mine3.png.

ATTRIBUTION
-----------
  * "Minesweeper" by Dan Henderson, 2021.
  * Double Lo-Res graphics: the DOLORES library by Marc Golombeck (DLCOREAMP
    files).
  * Graphics tool: Magic Pixels by Roby Sherman (Crow Cousins).
  * SPRITE.MAKER by Dan Henderson, 2021.
