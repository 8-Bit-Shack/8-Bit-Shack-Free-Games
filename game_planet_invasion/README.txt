==============================================================================
GAME TITLE : Planet Invasion
GAME NAME  : planet_invasion
FOLDER     : game_planet_invasion
==============================================================================

ABOUT
-----
Low-resolution Apple II shooter in the style of the classic Defender. You are
the fighter pilot: shoot the enemy UFO as many times as you can before it
shoots you, and avoid running out of fuel by shooting the fuel rocket that
appears from time to time. You have 5 smart bombs that wipe out everything on
the screen. It is a single-level, endless-scrolling game and your high score
is saved. Choose keyboard or joystick at boot (joystick: button 0 fires,
button 1 is the smart bomb); press K on the main screen to change the keys and
save the setup. Runs on all Apple II computers at 1 MHz; on an Apple IIgs you
may need to turn on Alternate Display Mode before booting, because the game
uses text page 2.

FILES
-----
PLANETCO.DSK (DOS 3.3); Planet Invasion.pdf (the game manual); Planet
Invasion.png (title banner); source/ (Applesoft BASIC listings as .bas.txt and
Merlin 6502 source as .s); disk_contents/ (every file from the disk image,
named NAME#TTAAAA). The sprites and frames are data and have no source.
